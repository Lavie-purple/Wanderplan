## 旅游规划网站 MVP 实现计划“左面板选择 + 右侧地图联动”核心体验”### 技术栈- React 18 + Vite + TypeScript- Tailwind CSS（清新文艺风格：暖白背景 #FAFAF7、苔藓绿主色 #5B8C5A、暖橙辅色 #E8A87C）- Leaflet + react-leaflet + OpenStreetMap（免费无需Key）- Zustand 状态管理（左侧操作 → store → 右侧地图响应式更新）- Framer Motion 动画- Lucide React 图标### MVP 功能范围**Step 1: 旅游偏好测评**- 3个问题（旅行风格/活动偏好/节奏偏好），每题3个卡片选项- 选中动画反馈 + 顶部进度指示- 完成后生成旅行人格标签，自动进入下一步**Step 2: 城市选择**- 6-8个推荐城市卡片（城市风景图 + 名称 + 简介 + 偏好匹配标签）- 点击城市 → 右侧地图 flyTo 该城市并放大- 可选多个城市，已选高亮，地图叠加标记- 搜索框筛选**右侧地图（全程可见）**- Leaflet 地图，初始视角中国全境- 实时跟随左侧操作：flyTo动画、颜色标记、弹出信息窗### 文件结构``````src/components/layout/AppLayout.tsx      # 左右分栏布局src/components/layout/StepIndicator.tsx  # 步骤进度条src/components/steps/PreferenceQuiz.tsx  # 偏好测评src/components/steps/CitySelector.tsx     # 城市选择src/components/cards/PreferenceCard.tsx  # 偏好选项卡片src/components/cards/CityCard.tsx         # 城市卡片src/components/map/MapPanel.tsx          # 地图面板src/store/useAppStore.ts                 # Zustand全局状态src/data/cities.ts                        # 城市预设数据src/data/quizOptions.ts                   # 测评选项src/types/index.ts                        # TypeScript类型src/App.tsx / main.tsx / index.css``````### 实现步骤1. **项目初始化**：Vite创建React+TS项目，安装tailwindcss、leaflet、react-leaflet、zustand、framer-motion、lucide-react2. **类型定义 + 预设数据**：定义City、Preference、Quiz等类型；编写6-8个城市数据（含经纬度、景点、标签）和测评选项3. **Zustand store**：currentStep、preferences、selectedCities、activeCardId、mapCenter/mapZoom等状态4. **布局组件**：AppLayout左右分栏（左45%可滚动 / 右55%地图固定）、StepIndicator步骤条5. **地图面板**：集成react-leaflet，监听store变化执行flyTo，城市管理标记点和Popup6. **Step1 偏好测评**：卡片式问题展示，选中状态管理，完成逻辑，旅行人格标签生成7. **Step2 城市选择**：城市卡片列表，搜索过滤，点击选择联动地图，多选管理8. **动画打磨**：卡片hover/选中动画，地图flyTo过渡，步骤切换动画### 地图联动核心逻辑左侧卡片点击 → store更新activeCardId/mapCenter/mapZoom → MapPanel响应 → map.flyTo() + openPopup()
